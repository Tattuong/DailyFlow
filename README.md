# DailyFlow

Guided routines. Each step has a duration and a short cue, then the next one.

Package: `com.DailyFlowMNG.DailyFlow`

Remote config: [N304.json](https://api2.blwsmartware.net/N304.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product ID | Type |
| --- | --- |
| `df_pack_1` … `df_pack_10` | Consumable coins |
| `df_remove_ads` | Non-consumable |
| `df_pro` | Non-consumable, more than 8 custom routines |

Routines and session history stay on the device. No account.
